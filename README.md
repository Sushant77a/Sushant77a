### [TimeIsNow](https://github.com/Sushant77a/TimeIsNow) · Personal Life Dashboard & Assistant

A full-stack application for managing todos, journals, schedules, finances, goals, habits, practices, daily entries, and notes.

| Area | Implementation |
|---|---|
| Backend | .NET 10, ASP.NET Core, Clean Architecture |
| Security | JWT access tokens, rotating HTTP-only refresh cookies, MCP tokens |
| Data | MySQL 8, Entity Framework Core 10, migrations |
| Frontend | React 19, TypeScript, Vite, Tailwind CSS |
| AI & MCP | OpenAI/Anthropic-compatible providers, Streamable HTTP MCP server |
| Operations | Docker Compose, health endpoints, Swagger, local development tooling |
| Quality | Playwright end-to-end tests |

<details>

- Designed category-scoped life-management workflows across multiple domains

- Added deterministic and AI-assisted weekly briefings
- Exposed an MCP server with authenticated tools for a signed-in user's data
- Developed a React/TypeScript client and Playwright end-to-end tests
- Included MySQL migrations, Docker configuration, and local setup automation
